## 1. Yönetici özeti

### 2.4 Normal onboarding ile MCP onboarding

Karar: ayrı yolculuklar, ortak ürün içi giriş noktası. Normal “hello world” bir plan; MCP “hello world” credential → config → protocol call → proposal zinciridir.

Bugünkü kod akışı:

1. Bağlantı rehberi bütün kanvas üyelerine, token yönetimi yalnız owner’a görünür (`web/src/components/CoPronoiaPanel.tsx:372-390`).
2. Rol yoksa grup/site admin rol tanımı istenir; roller + etiket seçilip anahtar basılır (`web/src/components/CoPronoiaPanel.tsx:174-208`).
3. Sunucu Co-Pronoia canvas ve rol kapsamını doğrular, `tma_...` secret üretir (`server/src/agentRoleService.ts:157-181`).
4. Raw secret yalnız mint response’unda döner ve UI’da o anda gösterilir (`server/src/routes.ts:546-562`; `web/src/components/CoPronoiaPanel.tsx:92-107`).
5. Rehber endpoint, CLI ve `.mcp.json` verir; ilk çağrı `get_brief` denir (`web/src/components/CoPronoiaPanel.tsx:37-88`).
6. `get_brief`, normal ajan için `get_state → submit_proposal` sırasını açıklar (`server/src/mcp/mcpServer.ts:143-150,190-202`).
7. `get_state` grafı ve `headSeq`’i döndürür (`server/src/mcp/mcpServer.ts:240-275`).
8. `submit_proposal` intent’leri doğrular fakat uygulamaz (`server/src/mcp/mcpServer.ts:499-529`).
9. `approve_proposal`, proposal’ı normal commit hattına indirir; çakışırsa branch sonucu döner (`server/src/mcp/mcpServer.ts:582-606`).

Yerel MCP endpoint’i Bearer token ile tek POST ve stateless transport kullanır (`server/src/mcp/mcpRoutes.ts:12-51`). 2026-07-28 MCP spesifikasyonu tek POST endpoint ve protocol-level session kaldırılmasını doğrular (https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http — erişim 16.08.2026; içerik açılarak destek doğrulandı).

Claude Code quickstart `claude mcp add --transport http`, Bearer header, status ve kullanım akışını doğrular (https://code.claude.com/docs/en/mcp-quickstart — erişim 16.08.2026; içerik açılarak destek doğrulandı). `/doctor` ve `/mcp` desteği resmî troubleshooting’dedir (https://code.claude.com/docs/en/troubleshooting — erişim 16.08.2026). Remote HTTP/Bearer referansı: https://code.claude.com/docs/en/mcp — erişim 16.08.2026.

Önerilen wizard: Rol → Anahtar → İstemciye bağla → get_brief/get_state başarısını doğrula → küçük bir ilk proposal gönder. `lastUsedAt` herhangi authenticated MCP isteğinde en çok 60 saniyede bir güncellenir (`server/src/agentRoleService.ts:230-249`); dolayısıyla yalnız “istek geldi”yi kanıtlar, `get_state` başarısını değil. Tool enum/result/timestamp içeren, içeriksiz telemetry gerekir.

Hata ayrımı: 401 geçersiz/iptal token, 403 artık Co-Pronoia olmayan canvas, GET/DELETE 405 stateless-POST endpoint demektir (`server/src/mcp/mcpRoutes.ts:26-51`). Claude quickstart da status ayrımlarını ve curl’de 404/405 ulaşılabilirlik, 401/403 auth sinyalini açıklar (https://code.claude.com/docs/en/mcp-quickstart — erişim 16.08.2026).

### 2.5 Aktivasyon metrikleri

Oranlar dış benchmark değil, 16.08.2026 başlangıç hipotezidir.

Ana primary `MAIN_A10`: ilk Dashboard’dan 10 dakika içinde ≥5 düğüm, ≥4 kenar ve seed dışı ≥1 main commit. Başlangıç hedefi ≥%40. Guardrail: median ≤5 dk/p90 ≤15 dk; first-prompt commit veya typed fallback p95 ≤15 sn ve typed failure ≤%10; activated cohort D7±1 dönüş ≥%25.

MCP primary `MCP_A15`: mint’ten 15 dakika içinde aynı attempt’te `get_brief success → get_state success → submit_proposal success`. Başlangıç hedefi ≥%50. Guardrail: get_state median ≤5 dk/p90 ≤10 dk; supervisor kurulu cohort’ta proposal applied/branch ≥%60 ve ≤30 dk; activated cohort D7±1 MCP çağrısı ≥%30.

Event alanları yalnız `event, ts, activation_attempt_id, path, workspace_count_bucket, canvas_type, result_code, duration_ms_bucket, node_count_bucket, edge_count_bucket, head_seq_bucket, mcp_tool, proposal_status, error_code` olmalıdır. Prompt, node/proposal içeriği, kullanıcı adı, e-posta, persona, raw token ve davranış profili toplanmamalıdır.

Önerilen retention: user↔activation bağı 8 gün, içeriksiz raw event 30 gün, aggregate cohort 13 ay. Bunlar hukuki zorunluluk değil, ürün/veri-minimizasyon önerisidir.
